# Changelog

## 0.1.0 — 2026-11-14

First public source checkpoint of Metivolve / Gents, preserving session 1 history.

- Local Rust company harness, governed MCP tools and independent stdio / private
  HTTP/SSE transports, with a source-derived cookbook.
- Per-agent permissions, scoped memory, planning and local task verification.
- Public introduction, guided setup, hardware/time and ownership calculators,
  support, privacy, terms and control-readiness pages.
- Local language, image and speech experiments with frozen before/after evidence;
  experimental adapters remain unpromoted and no universal task claim is made.
- MIT project license, contribution guide and source-only publication boundaries.

Model weights, datasets, credentials, private execution records, generated builds
and local Python environments are excluded. See [current capabilities](docs/131-model-capability-scorecard.md)
and [release notes](docs/versions/0.1.0.md) for limitations.
