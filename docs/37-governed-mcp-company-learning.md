## Live work and mentoring

`config/company.mcp-development.json` assigns only a planner and an engineer.
The installed 30B coder is used after the 4B attempt demonstrated a real review
loop. `scripts/mcp-company-development.mjs` freezes the operator task, approves
the exact digest and installs a narrow native-memory/file policy. Its `watch`
mode emits changed status only; inference is not used for polling. Existing run
IDs and their failed/cancelled outcomes are retained. No observation timeout
authorizes duplicating a job.

The first trial exposed two genuine harness issues: QA invented an excluded
shell-test prerequisite and later demanded a model-written "definitive receipt"
despite actual native calls. The fix supplies canonical native receipts and
scope clarifications to the reviewer. Required MCP calls can now be frozen in
intake and checked deterministically before model QA; prose cannot waive them.
These changes do not waive independent code review, fixed tests or promotion.

The retained revision trial then exposed stale-evidence feedback: successful
native reads were present, but repeated worker self-assessments and obsolete
native gate failures kept being echoed as recent evidence. Normal worker
packets now include actual tool results (including real failures) and unresolved
content QA, not self-assessment prose or superseded native gate snapshots. The
current native audit state is supplied separately every turn. A regression test
preserves real failures while rejecting this false-failure echo. Failed native
completion also enters bounded replanning. A tool may opt into a bounded
read-only recovery proposal; it cannot auto-write a plan, expand permissions or
execute without the existing admin and current-policy gates.

Local code remains quarantined in each run workspace. The `packet_budget`
candidate is included with its source attribution and independent acceptance
suite. The local 30B revision resolved the reported lint without waivers; strict
all-target Clippy, workspace tests and the locked offline workspace build pass.
Native token admission uses this pure helper and still counts the actual model's
chat template/tokenizer. It never truncates required task content to fit.
