These are exactly the source families available to this graph protocol. It excludes unrelated file readers, code verification and side effects from that prompt view. Other planning modes retain the full catalog. The CEO still chooses input owners, transformations, output projections and staffing. Owner requirements and source arguments are never truncated to make a prompt fit.

The workflow runner stops on infrastructure failures requiring host diagnosis rather than automatically requesting another contract repair.
