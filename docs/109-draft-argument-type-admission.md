## Shared native value rules

`mcp/src/component_api/metadata.rs` recognizes only exact wire descriptors emitted by the owned native ABI. It converts the descriptor to the existing `WireType` representation and calls the same bounded literal validator used by actual source marshalling. This adds no alternate numeric conversions, general JSON Schema implementation, package, network dependency or source execution. Descriptor size and type depth are bounded. Exact normalization rejects extra fields, changed limits/patterns, malformed tags, unsupported integers and foreign machine-size widths. Vector/slice and String/str metadata intentionally share value rules, consistent with the existing ABI.

The public helper checks value compatibility only. It does not establish source identity, source custody, correctness, result presence, provenance, task qualification or tool authority. Owner preparation still privately re-parses the pinned source and repeats the actual ABI validation. Runtime still validates receipt lineage and derived argument presence. Result references remain unresolved null slots during discovery; no result, default, function, actor or graph is supplied by the host.

`owned_selection::review` now applies this helper to each resolved owner-data argument against that exact selected function's positional parameter metadata. A mismatched projection fails native draft validation before pending preparation is retained. The normal CEO planning rejection audit and the existing phase-local structural-failure policy then apply. The model remains responsible for choosing another valid projection or asking the user about actual missing requirements. Neither private acceptance oracle nor replacement task-specific pointers are added to prompts.
