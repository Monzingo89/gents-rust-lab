## The framework repair

`Tool::frozen_source_admission` is a default-deny, read-only extension point. Registry admission still requires read-only operation, no external effects, a valid phase and current source-actor grant. Existing pure/pinned-file rules remain. The owned-library implementation inspects the exact SOW binding, active job, actor, source/API hashes, function, input hash and supported argument shape. It executes no library during admission. Execution repeats those checks. The tool remains `deterministic=false`.

Writer preparation uses the approved source actor's scope and rechecks the library before copying a captured result. A regression covers admission without execution, denied actor/input changes, source execution with a native receipt, refusal after the library changes, then exact writer write/readback after restoring the pinned bytes. Generic contract execution no longer needs a tool-name exception to recognize this class. No permission ceiling, expected answer, source implementation or QA verdict was changed.
