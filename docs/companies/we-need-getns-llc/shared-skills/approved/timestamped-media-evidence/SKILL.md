# Timestamped media evidence
ID: timestamped-media-evidence
Version: 1.0.0
Status: APPROVED-DEMO
Scope: reusable procedure, not company policy
Inputs: assigned task, source catalog, permitted tools
Outputs: structured results, evidence references, unresolved issues
Procedure: Inspect media capabilities. Segment audio within backend limits and retain intervals. Sample video frames and resample around relevant changes. Read visual-only values directly. Link observed facts to original timestamps and saved frames. Treat uncertain IDs and dates as unresolved until checked.
Validation: require source locators, actual execution evidence where applicable, and explicit failure states.
Permissions: inherits the harness tool allowlist; cannot expand it.
