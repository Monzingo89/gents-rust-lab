## A separate data ABI for source reuse

`mcp/src/component_api/` separates source/interface discovery, supported types, literal encoding and a small trusted result codec. The installed-toolchain sandbox now shares its compiler/runtime isolation between frozen acceptance and component invocation; acceptance semantics remain unchanged. No new dependencies were added.

The interface supports bounded public non-generic functions with booleans, UTF-8 strings, unit, integer primitives through 64 bits, tuples, vectors, tagged Option/Result and immutable input slices/str. Integers cross JSON as range-checked canonical decimal strings, preserving full 64-bit values through JavaScript. Machine-size integer widths are part of the API digest, so changing host width requires a new reviewed binding. Floats, mutable references, arbitrary user types, generics, unsupported signatures and effects fail closed. Input/output arrays, nesting, text, total wire bytes, process output, time and observed memory are bounded.

API SHA-256 and source SHA-256 are separate: changing an implementation without changing its interface preserves only the API identity. Invocation requires both exact pins. The generated driver only marshals typed data, calls the parsed function identifier and encodes its result; it does not implement domain logic or acceptance answers. The trusted codec has stdout access; the candidate dialect still excludes host I/O. Compiler and runtime use the existing deny-default macOS Seatbelt profiles, cleared environment, confined scratch, process-group cleanup and limits. Unsupported OS isolation has no unsandboxed fallback.

`gents-rust-component` is a private bounded-stdin host helper. `scripts/mcp-component-probe.mjs` checks sealed review-package/source custody, copies bounded owned helper bytes to a private executable snapshot and records its hash before describing or invoking source. It accepts no arbitrary command flags or shell. This is an explicit owner utility, absent from the MCP registry. A copied helper hash is not reproducible-build or same-user-attacker attestation. Stored review evidence grants no authority for a new task.
