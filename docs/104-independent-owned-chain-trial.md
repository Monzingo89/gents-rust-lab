# Independent verification of an owned component chain

The level-17 `owned-allocation-chain` benchmark exercises a capability absent from the preceding independent-root benchmarks: one actual native return value becomes a positional argument to a later owned invocation. Both calls reuse the same locally authored, previously qualified allocation component. Only the later result is a requested file. This is a medium synthetic dependency test, not a claim of universal progression, distinct-library composition or financial compliance.

## Frozen task and independent observer

The fixture freezes literal inputs and an empty second-call argument slot. The local CEO must select the source actors, compatible return projection, edge, final path and separate publication actor. Expected values remain in the host-only fixture oracle; neither the planning fields nor the workspace contains them. The BigInt oracle checks exact quota and remainder arithmetic independently of the retained Rust source. Frontier changes in this phase concern the benchmark, custody observer and verification, with no domain implementation supplied to the company.

`scripts/mcp-owned-edges.mjs` verifies the CEO-selected frozen dependency against the task and reconstructs native lineage from the actual parent tool journal. Checks bind the producer identity, actor, source/API hashes, request/result/value hashes, run and current policy revision. The ordinary workflow verifier separately matches these tool receipts to canonical native audit records. Synthetic unit evidence alone cannot establish canonical authority or model capability.

Prepared metadata distinguishes a template hash from a literal input hash. The observer verifies the frozen recipe hash, actual resolved argument hash, native SQL recipe/lineage hashes, source custody, approved staging, exact final bytes and readback. Receipt-only nodes have no publication obligation; the observer rejects file operations and filesystem entries at their receipt identities. Extra operations and unrecognized or duplicate prepared receipts fail review. Existing literal fixtures keep their prior identities.
