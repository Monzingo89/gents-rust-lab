# Typed component edge boundary

The next data-flow layer must join an approved producer receipt to an approved consumer argument without treating model text, an output file or an inspected interface as authority. `mcp/src/component_api/connections.rs` now provides the pure type/value boundary for that work. Actual receipt-backed component edges and CEO edge planning are not implemented or qualified by this module.

`connections::describe` compares a declared producer return projection with a declared consumer positional argument. It parses both owned pure-Rust interfaces and returns their exact source/API hashes, function names, projection, argument position and matching wire schema. Root values, supported Option/Result data tags, fixed tuple positions and bounded vector indices are supported. Vec/slice and String/str share wire representations; numeric types must match exactly. No numeric coercion, array wrapping, fallback value, dependency download, compilation or candidate execution occurs. Hardware-sized integer widths remain part of the existing API identity, so equal host widths do not silently turn distinct integer types into interchangeable types.

`connections::validate_output` uses the existing bounded wire-type codec rules to reject invalid tags, extra tags, noncanonical/out-of-range integers, oversized arrays/text and outputs beyond 8192 JSON bytes. The native invocation adapter now checks every successful output before attaching native identity metadata or recording successful owned-call observations. This adds a second host-side check alongside the existing typed compiler/encoder constraints; it is not evidence that an oversized output previously escaped those constraints. Rejected output cannot become a successful owned-call receipt. The outer native transaction, source sandbox, actor/phase checks, canonical audit and independent task acceptance remain authoritative.

`connections::project_output` checks the complete typed value and declared projection, then requires the selected value to exist in that actual result. A statically valid `/some/0` edge may be absent when the result is `none` or an empty vector; that is an error rather than permission to choose a different branch or value. Empty pointer means the complete return value. Pointers are bounded to 160 bytes and six data segments; array indices are canonical and at most 255. Metadata tags such as `none` are not data projections.

These helpers deliberately have no database, filesystem, network, model, tool registry or permission adapter. In particular, calling them with a fabricated JSON value establishes no provenance. The future resolver must obtain values only from exact current-run/current-epoch canonical native observations. Tests cover valid interfaces without running candidates, mismatched widths/signs, unsupported fields, malformed/bounded indices, missing tags/elements and runtime value limits.

## Remaining integration contract

The owner-frozen edge representation must bind the producer invocation ID and selected return pointer to a consumer invocation ID and positional argument. It must capture exact source/API/function identities, the other literal arguments and the graph identity. Changing a literal, producer, projection, actor, source, policy epoch or destination requires a different reviewed contract. An inspected compatible interface grants no invocation or cross-agent access.

The resolver must reuse or extract the existing `bound_sources` receipt observer rather than introduce a second weaker provenance path. It must verify successful canonical producer audit, exact request/result/projection hashes, current policy epoch and recipient `memory_from` controls. It must resolve and validate a bounded argument tuple before execution, bind the resolved input digest into the consumer observation, and retain producer receipt identity in lineage. Missing/failed/revoked/stale producers leave the consumer unexecuted. Output files and model messages never supply argument values.

Graph admission must check unique IDs/argument slots, complete argument coverage, source custody, bounded node/edge counts, static type compatibility, acyclicity and ordered actor staffing. Conditional projections fail on absent branches; no implicit branch handler or default is authorized. Existing independent roots and historical owner-frozen input hashes must remain backward compatible rather than acquire a silently different meaning.

Qualification requires adversarial native tests for fabricated/changed receipts, cross-run/cross-epoch/cross-actor sources, changed source/API/arguments, graph cycles, missing branch values and replayed consumer writes. A new reviewed actual-company benchmark must require at least one component result to change another component's input, with the CEO choosing the graph and an independent oracle kept outside prompts. Only that later qualification can establish receipt-backed component chaining. No such capability, model training, enterprise compliance or universal task completion is claimed here.

That later unchanged mapped-fixture trial passed exact native/output verification on the 448-test build. It exercises successful output validation on both stored libraries; it does not exercise or qualify component edges.

`component-connection-private-boundary-proof.json` also records an actual isolated private helper probe: a protocol-only String producer returned 4096 bytes successfully; requesting 4097 bytes exited 67 inside the existing encoder and returned a failed invocation with null output. The initial probe incorrectly expected the adapter's request-rejection envelope for that failure; the corrected probe preserves the observed invocation-failure shape. This confirms an existing encoder boundary, not a newly fixed vulnerability. The source is an explicitly frontier-authored infrastructure fixture, not a domain solution, qualified component, company task or native MCP authority receipt.
