# Full-body Gents sprites

Generated with the built-in image generation tool from the operator's twenty original portraits. Originals are unchanged and are used in hover previews and dossiers. Each PNG has transparent alpha and four row-major cells in a 2 × 2 grid. Runtime alpha bounds remove cell padding without modifying the source assets. Runtime head-only crops are used inside recharge pods.

- `fullbody-1-v1.png`: fox, crystal, moth, dwarf.
- `fullbody-2-v1.png`: robot, water dragon, stone golem, alien scholar.
- `fullbody-3-v1.png`: faun, elf, mushroom, jade spirit.
- `fullbody-4-v1.png`: Luna / moon, Coral / octopus, Ember / emerald dragon, Sage / cactus.
- `fullbody-5-v1.png`: Onyx / raven, Rowan / stag, Boreal / yeti, Atlas / lion.
