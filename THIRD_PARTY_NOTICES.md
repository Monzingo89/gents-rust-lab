# Third-party material

Original project software and documentation are provided under the [MIT License](LICENSE). Existing third-party license notices continue to apply to their respective material.

Model weights are not included in the repository. Each model, dataset, adapter, dependency, font and externally supplied media asset keeps its own license and terms. A local download or a checksum is not evidence of redistribution rights. Review provenance and license obligations before distributing a model, dataset or media asset; the project's MIT license does not replace those permissions.

Rust dependency identities are pinned in `Cargo.lock`; JavaScript dependency identities are pinned in `package-lock.json`. Installed dependency packages contain their respective notices. Model provenance and local integrity review are separate from software licensing and from security or compliance assurance.

A complete release asset and dependency inventory remains part of the pre-publication review. No new third-party code, model or asset is licensed by this notice.

Local optional media engines are pinned in [mcp/media/requirements.lock](mcp/media/requirements.lock): MFLUX is MIT; Piper is GPL-3.0 and runs in a separate process. Dependency licenses still apply. Model files are excluded from Git. The reviewed image repository declares FLUX.2 Klein 4-bit weights Apache-2.0; the Piper LJ Speech voice model card identifies its training dataset as public domain. These statements do not replace each component's notices or a redistribution review. Sources and exact downloaded file identities are recorded in [config/media.local.json](config/media.local.json); setup and limitations are documented in [mcp/media/README.md](mcp/media/README.md).
